# Prompt Template

Use this order when compiling a fresh image prompt:

1. **Character** — name, approved spec, posture, silhouette, must-have details.
2. **Action** — one emotional action, physical logic, visible cost.
3. **Composition** — framing, camera distance, angle, lens feeling, screen-left / screen-right logic, visible hand, gesture direction, depth of field.
4. **Environment** — one location, one temperament, one environmental force arguing with the character.
5. **Lighting** — time of day, contrast, practical light, haze, chromatic winner.
6. **Style** — stylized semi-realistic, polished digital rendering, prestige animation / Style B, not photorealistic.
7. **Withholding** — state what the frame refuses to show.

Use compact phrasing. If the image starts to bloat, remove props and background incidents before touching character clarity.
